# UI Design System & Brand Guidelines

## 1. Color Palette (Semantic Clinical System)
- **Primary Canvas**: `#F8FAFC` (Slate 50) — Calm, clean, clinical neutral.
- **Structural Surfaces**: `#FFFFFF` (White) with subtle `#E2E8F0` hairline dividers.
- **Brand Navy**: `#0F172A` (Slate 900) — Deep clinical authority and high-contrast typography.
- **Primary Accent**: `#2563EB` (Blue 600) — Concentrated strictly at interactive primary action points (CTAs, active tabs, selected states).
- **Clinical Emerald**: `#16A34A` (Emerald 600) / `#059669` (Teal 600) — Normative biological status and verified evidence.
- **Clinical Amber**: `#D97706` (Amber 600) — Borderline analyte values and advisory notices.
- **Emergency Crimson**: `#DC2626` (Rose 600) — Emergency safety interceptors and acute red-flag alerts.

## 2. Zero-Pill & Metadata Discipline
- **No Static Pill Enclosures**: Metadata (dates, categories, timestamps, LOINC codes) is rendered as unboxed text using subtle typographic separators (`·` or `/`).
- **Functional Segmented Controls**: Clickable tabs and filters are clean segmented buttons (`<button>`) with clear active/inactive visual states.
- **Anti-Slop Restraint**: Zero robot illustrations, zero cyberpunk glows, zero fake "97% AI accuracy" meters, zero mechanical code-comment headers (`//`).

## 3. Typography Scale & Hierarchy
- **Font Families**:
  - Primary Display & Body: `Plus Jakarta Sans`, `-apple-system`, `sans-serif`
  - Telemetry & Lab Data: `JetBrains Mono`, `monospace` (paired with `tabular-nums`)
- **Type Scale**:
  - Hero Display: 36px–60px, font-extrabold, tracking-tight, line-height 1.12
  - Section Headings: 24px–36px, font-bold, tracking-tight
  - Subheadings: 16px–20px, font-semibold
  - Body Text: 14px–16px, line-height 1.6, max measure 65–75ch
  - Micro-copy & Metadata: 11px–12px, font-mono or font-medium
