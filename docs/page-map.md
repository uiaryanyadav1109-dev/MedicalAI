# Page Map & Routing Specification

All routes are fully functional via the client-side router with `window.history` synchronization:

| Route | Page Title | Primary Functional Role |
| :--- | :--- | :--- |
| `/` | Home | Comprehensive showcase: Hero, Trust, Problem/Solution, Core Capabilities, 8 interactive sandboxes, Safety, FAQ, CTA. |
| `/platform` | Platform Architecture | Technical overview of the 4 platform layers (Ingestion, Adaptive Inquiry, Safety, Export). |
| `/features` | Features Directory | In-depth directory of all 8 core product capabilities with live interactive preview modules. |
| `/how-it-works` | How It Works | 5-step clinical intake protocol breakdown with interactive deep-dives. |
| `/safety` | Clinical Safety | Deterministic safety rails, red-flag screening, and triage taxonomy governance. |
| `/for-patients` | Patient Experience | Patient-centered benefits: symptom organization, lab decoding, and appointment preparation. |
| `/for-doctors` | Clinician Experience | Clinical collaboration benefits: 1-page HPI handoff, ambulatory vitals review, and zero-automation guarantee. |
| `/security` | Security & Privacy | Zero-knowledge tokenized sharing, encryption protocols, and sovereign patient rights. |
| `/resources` | Educational Guides | Patient guides on lab tests, appointment preparation, and care timing. |
| `/faq` | Frequently Asked Questions | 12 critical medical safety and platform questions with search and category filtering. |
| `/contact` | Contact & Inquiries | Interactive validated form for clinical partnerships, institutional pilots, and support. |
| `/about` | About Medical AI | Mission statement, founding principles, and anti-slop healthcare manifesto. |
| `/privacy` | Privacy Policy | Full data sovereignty, retention, and non-commercialization disclosure. |
| `/terms` | Terms of Service | Legal boundaries, permitted use, and non-clinical informational purpose. |
| `/medical-disclaimer` | Medical Disclaimer | Prominent clinical notice regarding diagnostic limits and emergency protocols. |
| `/signin` / `/login` | Sign In Page | Two-column desktop layout, patient/clinician toggle, password visibility, Google OAuth readiness. |
| `/signup` | Create Account Page | Two-column desktop layout, password strength & criteria checklist, non-prechecked terms, optional phone. |
| `/forgot-password` | Reset Password Request | Account enumeration protected password reset dispatch. |
| `/reset-password` | Password Update | New password submission with criteria checklist and strength meter. |
| `/verify-email` | Email Verification | Email confirmation instructions with 60s resend cooldown timer. |
